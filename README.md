# CST3144 Full Stack Development

## After-School Activities

A Vue.js web application that allows students and parents to browse and purchase after-school activities.

## Live Website
https://checongwong-cell.github.io/coursework-CST3144/

## Features
- Display available lessons and activities
- Sort lessons by subject, location, price and availability
- Add and remove lessons from shopping cart
- Checkout with customer information
- Retrieve lessons from the backend using Fetch API
- Submit orders to the backend

## Technologies
- Vue.js
- JavaScript
- HTML
- CSS
- Node.js and Express.js backend
- MongoDB Atlas
